# Windows khởi động chậm

## Mô tả
Máy mất nhiều thời gian từ lúc bật nguồn đến khi có thể làm việc bình thường.

## Khoanh vùng
- Chậm trước hay sau màn hình đăng nhập?
- Máy dùng HDD hay SSD?
- Sau đăng nhập CPU, RAM hoặc Disk có lên cao không?
- Lỗi xảy ra sau Windows Update hoặc cài phần mềm mới không?

## Kiểm tra
1. Mở Task Manager > Startup apps và xem ứng dụng khởi động cùng Windows.
2. Kiểm tra CPU, Memory, Disk sau đăng nhập.
3. Kiểm tra dung lượng trống ổ C.
4. Kiểm tra Windows Update và phần mềm bảo mật đang chạy nền.
5. Xem Event Viewer khi cần chẩn đoán sâu.

## Xử lý
- Tắt Startup app không cần thiết theo chính sách IT.
- Gỡ phần mềm không còn sử dụng nếu được phép.
- Hoàn tất Windows Update rồi khởi động lại.
- Nếu HDD thường xuyên 100%, kiểm tra sức khỏe ổ đĩa và cân nhắc nâng cấp SSD theo quy trình tài sản.

## Chuyển cấp
Máy có lỗi ổ đĩa, BSOD, thời gian boot bất thường dù đã tối ưu phần mềm hoặc nghi lỗi phần cứng.

## Từ khóa
Windows khởi động chậm, boot slow, startup, disk 100, HDD, SSD
