# Excel / Word mở file chậm hoặc bị treo

## Mô tả
Word hoặc Excel mất nhiều thời gian mở file, Not Responding, chỉ một file bị lỗi hoặc file trên ổ mạng mở rất chậm.

## Khoanh vùng
- File cục bộ hay file trên File Server/OneDrive?
- Một file hay mọi file?
- Chỉ một máy hay nhiều máy?
- File có dung lượng lớn, nhiều công thức, liên kết ngoài hoặc macro không?

## Kiểm tra
1. Sao chép một bản file về thư mục cục bộ được phép và thử mở để phân biệt lỗi mạng với lỗi Office/file.
2. Kiểm tra Task Manager và dung lượng ổ đĩa.
3. Kiểm tra add-in nếu mọi file đều chậm.
4. Kiểm tra liên kết ngoài, macro và nguồn dữ liệu với file Excel phức tạp.

## Xử lý
- Đóng các ứng dụng Office không cần thiết.
- Khởi động lại ứng dụng/máy khi phù hợp.
- Cập nhật Office theo kênh quản trị của doanh nghiệp.
- Dùng Safe Mode để khoanh vùng add-in nếu IT có quyền thực hiện.
- Với file quan trọng, luôn tạo bản sao trước khi Repair hoặc chỉnh cấu trúc.

## Chuyển cấp
- File nghiệp vụ quan trọng có dấu hiệu hỏng.
- Nhiều người cùng không mở được file trên server.
- Macro/add-in nghiệp vụ lỗi.
- Có nguy cơ mất dữ liệu.
